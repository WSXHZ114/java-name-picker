# Java 随机点名器

一个用 Java 写的控制台随机点名程序，支持作弊配置和抽取次数记录。

## 项目简介

这是一个 Java 练习项目，用于随机抽取名单中的名字。
支持从文件读取名单、记录抽取次数，以及通过配置文件指定第几次抽取特定前缀的名字。

## 功能特性

- 从 `Name.txt` 读取名单，格式为 `姓名-性别-年龄`
- 每次运行随机抽取一个名字
- 自动记录抽取次数到 `Name-Count.txt`，从 0 开始
- 支持作弊：通过 `Name-Cheating.txt` 指定第几次抽取某个前缀的名字（需要手动创建文件）
- 文件自动在程序所在目录创建，IDEA 和 jar 都能运行

## 环境要求

- JDK 8 或更高版本
- 文本文件统一使用 **UTF-8** 编码保存（否则中文姓名可能显示乱码）

## 文件说明

| 文件名 | 作用 | 格式示例 |
|---|---|---|
| `Name.txt` | 名单文件 | `李强-男-22` |
| `Name-Count.txt` | 抽取次数记录 | `2` |
| `Name-Cheating.txt` | 作弊配置（可选） | `3/李强` |

> `Name.txt` 每行一个信息，用 `-` 分隔三段信息，三段都不能为空。
> 没有做出内容判断，抽取时按照姓名为准（第一段信息）
> 不满足格式的行会被自动跳过。

## 使用方法

### 方式一：在 IDEA 中运行

1. 用 IntelliJ IDEA 打开项目，确认 JDK 已配置
2. 运行 `NameTest.java` 的 `main` 方法
3. 第一次运行会自动创建 `Name.txt`、`Name-Count.txt`
4. 在 `Name.txt` 中填入名单，每行一个，格式为 `姓名-性别-年龄`
5. 再次运行即可抽取

### 方式二：运行 jar 包

1. 用 IDEA 的 Build → Build Artifacts 打包（产物为 `Man.jar`）
2. 把 `Man.jar` 放到任意目录
3. 双击 `运行.bat`，或在命令行执行：

```bash
java -jar Man.jar
```

4. 程序会在 jar 所在目录自动创建所需的 txt 文件
5.  在 `Name.txt` 中填入名单，每行一个，格式为 `姓名-性别-年龄`
6. 再次运行即可抽取

## 运行效果（首次运行后在Name文件写入内容）

```
第一次：
$java -jar Man.jar
已创建Name文件，请补充内容
已创建Name-Count并初始化

第二次：
$ java -jar Man.jar
张伟-男-21

第三次：
$ java -jar Man.jar
李娜-女-20
```

`Name-Count.txt` 会同步累加，记录已经抽了多少次。

## 作弊配置说明

在 `Name-Cheating.txt` 中按 `次数/姓名前缀` 的格式写入一行配置：

```
3/李
```

表示第 3 次抽取时，从所有姓李的人里随机抽一个。

- 程序只读取该文件的**第一行**
- 如果指定次数到了，但名单里没有匹配前缀的人，会输出 `没有'李'`
- 如果次数位置填的不是数字，程序会把配置重置为 `null` 并退出

### 核心原理

- `getBaseDir()`：判断程序是从 jar 运行还是从 IDEA 运行，从而定位到正确的数据文件目录
- 计数器：`Name-Count.txt` 里存的是"已经抽过的次数"，所以第 N 次抽取时该值为 `N-1`
- 作弊触发条件：`currentCount + 1 == 指定次数`
